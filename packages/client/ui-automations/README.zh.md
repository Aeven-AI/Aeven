# @aeven/client-ui-automations

## 摘要

侧栏打开 `/automations`，支持直接访问和刷新。创建与调整使用普通输入框和对话批准。宽版页面展示下次执行、最新结果、按触发能力筛选的推荐想法、暂停或恢复、手动执行、删除、展开结果、关联重试、明确确认结果，以及清除已结束的执行记录。单行 30px 控件行承载视图切换与主操作。卡片为 30px 表面圆角的纯白块，无描边；卡片操作使用共享按钮基础组件的紧凑尺寸。此页面使用与对话相同的已认证连接，不在浏览器中存储权威计划。

## 模型体验

此包不增加工具或提示词章节。选择推荐想法会填入包含任务、计划、所需资料和确认指令的本地化草稿；用户提交前不会发送。所属的[核心服务](../../core/automations/README.zh.md)说明对话管理和执行的模型影响。

## 已知限制和后续工作

此页面管理本地执行。可见历史每五秒刷新一次。外部写入批准续执行、通知及云端执行选择仍待实现。执行结果链接到普通对话地址。此页面不拥有持久状态，因此无需不变量安装器。
