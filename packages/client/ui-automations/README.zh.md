# @aeven/client-ui-automations

[English](README.md) | 中文

## 摘要

侧栏打开 `/automations`，支持直接访问和刷新。创建与调整使用普通输入框和对话批准。宽版页面展示下次执行、最新结果、按触发能力筛选、按类别分组并显示本地计划的推荐模板、一个个性化推荐入口、暂停或恢复、手动执行、删除、每个自动任务的执行记录、跨任务的执行记录视图、失败执行的重试、单条执行记录的移除，以及清除已结束的执行记录。每条执行记录都链接到该次执行的对话，结果保存在对话中。删除自动任务、移除单条执行记录、清除执行记录以及重试失败的执行，都会先在本页自己的对话框中确认。清除执行记录会移除所有已结束的记录，并归档各自的对话，使其离开侧栏。单行 30px 控件行承载视图切换与主操作。卡片为 30px 表面圆角的纯白块，无描边；卡片操作使用共享按钮基础组件的紧凑尺寸。读取邮件、日历或 GitHub 的模板在当前账户没有该组已连接且已启用的连接器时显示连接操作，点击会在设置中打开对应连接器。没有账户集成的组合不显示连接操作。此页面使用与对话相同的已认证连接，不在浏览器中存储权威计划。

## 模型体验

此包不增加工具或提示词章节。选择推荐模板会填入包含任务、计划、所需资料、安全限制和确认指令的本地化草稿，并要求模型先使用已了解的用户信息再提问；个性化推荐入口要求模型推荐三个适合用户的自动任务；用户提交前不会发送。所属的[核心服务](../../core/automations/README.zh.md)说明对话管理和执行的模型影响。

## 已知限制和后续工作

此页面管理本地执行。可见历史每五秒刷新一次。通知、已保存批准的查看界面及云端执行选择仍待实现。此页面不拥有持久状态，因此无需不变量安装器。
