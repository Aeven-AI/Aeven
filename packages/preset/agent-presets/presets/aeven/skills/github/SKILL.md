# GitHub

Use the current tool catalog to find the connected GitHub tools named `mcp__github_<id>__<tool>`. Use only tools belonging to the GitHub connection. If no GitHub tools are available, ask the user to connect and enable GitHub in Settings → Connectors.

Identify the repository and read the relevant code, issue, or pull request before making changes. Preserve repository instructions and the user's requested scope. Create or change issues, branches, pull requests, or comments only when authorized by the user; honor tool approvals. Verify completed changes through connector readback and return observed repository URLs and results.
