# Teams

Use the current tool catalog to find the connected Teams tools named `mcp__account_<id>__<tool>`. Use only tools belonging to that connection, matching the account shown in Settings → Connectors. If they are unavailable, ask the user to connect and enable Teams there.

Find the requested chat or joined team and channel before reading or composing a message. Preserve chat, team, channel, and message IDs from results. Sending, replying, editing messages, creating chats, and creating channels require approval. Confirm ambiguous destinations before posting; read back completed changes. This connector needs a work account and channel reads may require administrator approval. Member administration, presence, meeting transcripts and recordings, and tenant directory tools are unavailable. Report only observed results; a tool name in the catalog does not prove a call succeeded.
