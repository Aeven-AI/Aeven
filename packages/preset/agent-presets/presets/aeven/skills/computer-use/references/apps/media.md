# Media players

Spotify, Music and VLC.

- Playback state updates late. After pressing play or picking a track, read the window once more before acting again; a second click often pauses what just started.
- Give the search field focus before pressing Return. Elsewhere, Space and Return can toggle or restart playback.
- Search results load from the network and can show "no results" for a moment; read again before changing course.
- Double-click a track to play it. Queue options ("Play Next", "Add to Queue") sit in the track's More (`…`) menu or its right-click menu.
- Music's sidebar can drill into a sub-view; use the back button to return to the top level.
