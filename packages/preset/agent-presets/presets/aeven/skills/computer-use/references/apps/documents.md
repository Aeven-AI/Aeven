# Documents and notes

Word, Pages, TextEdit, Notepad, Notion and Obsidian.

- Long or formatted text: write a `.docx` or `.md` file and open it, or put it on the clipboard with `clipboard_write` and paste. Typing long text is slow and loses formatting.
- `set_value` on a text area replaces all of its text; `type_text` inserts at the caret. Read the field back after either.
- New documents show placeholder text ("New page", "Untitled", "Write…"). Typing replaces it; do not select and delete it first.
- Notion is made of blocks: Return starts a new block, Markdown shortcuts format as you type (`#` heading, `-` list, `[]` to-do), and Return on an empty list item ends the list. In code blocks Return adds a line inside the block and Shift+Return leaves it.
- To jump to the start or end of a long document, focus the text and use `cmd+up` / `cmd+down` on macOS or `ctrl+home` / `ctrl+end` elsewhere.
- Save before reporting the result when the app does not save by itself (TextEdit, Notepad, Word); Notion, Obsidian and Pages save as they go.
