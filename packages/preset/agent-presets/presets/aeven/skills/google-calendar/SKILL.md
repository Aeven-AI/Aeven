# Google Calendar

Use the current tool catalog to find the connected Calendar tools named `mcp__account_<id>__<tool>`. Use only tools belonging to the Google Calendar connection. If no Calendar tools are available, ask the user to connect and enable Google Calendar in Settings → Connectors.

Read the relevant calendars and events before answering schedule or availability questions. Resolve dates, time zones, attendees, and the target calendar from the user's request and observed results. Ask for missing details that affect scheduling. Create, update, or delete events only within the requested scope; honor tool approvals. Read back changed events and report their observed times and links.
