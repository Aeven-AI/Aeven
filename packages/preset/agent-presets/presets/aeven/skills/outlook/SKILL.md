# Outlook

Use the current tool catalog to find the connected Outlook tools named `mcp__outlook_<id>__<tool>`. Use only tools belonging to that connection, matching the account shown in Settings → Connectors. If they are unavailable, ask the user to connect and enable Outlook there.

Search and read the relevant messages before replying. Use message, folder, and attachment IDs from tool results. Preserve the user's recipients and attachments; send only after the requested content is ready and the user approves the tool call. Sending, replying, forwarding, drafting, moving, copying, deleting, and changing folders or attachments require approval. Read back completed changes. Mailbox rules, mailbox settings, and shared-mailbox administration are unavailable. Report only observed results; a tool name in the catalog does not prove a call succeeded.
