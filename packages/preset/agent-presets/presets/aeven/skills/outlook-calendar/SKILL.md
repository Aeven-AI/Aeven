# Outlook Calendar

Use the current tool catalog to find the connected Outlook Calendar tools named `mcp__account_<id>__<tool>`. Use only tools belonging to that connection, matching the account shown in Settings → Connectors. If they are unavailable, ask the user to connect and enable Outlook Calendar there.

Read calendars and the requested date range first. Keep calendar and event IDs from results, and confirm ambiguous dates, time zones, invitees, and recurring-event scope. Creating, updating, deleting, accepting, declining, forwarding, cancelling, and changing reminders require approval. Read back completed changes. Free/busy lookup depends on the account type; Microsoft personal accounts may not support it. Calendar permission management and room administration are unavailable. Report only observed results; a tool name in the catalog does not prove a call succeeded.
