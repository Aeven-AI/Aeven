# Gmail

Use the current tool catalog to find the connected Gmail tools named `mcp__account_<id>__<tool>`. Use only tools belonging to the Gmail connection. If no Gmail tools are available, ask the user to connect and enable Gmail in Settings → Connectors.

Search and read relevant messages before preparing a reply. Keep thread and message identifiers from tool results. Draft the requested content, preserving recipients and attachments supplied by the user. Send, delete, or modify messages only within the user's requested scope; honor tool approvals. Verify completed changes through connector readback and report only observed results.
