# Agent Note: 语音设置在设置页中准备语音模型

Status: implemented

[English](2026-09-30-voice-settings-model-preparation.md) | 中文

## Problem

语音设置在用户使用听写前展示模型大小、下载来源、内部准备步骤和详细的下载诊断。这些选择和实现细节让基本的语音功能看起来像安装工具。

## Decision

该区块为每个识别器显示一个语音模型状态，并提供「下载」或「重试」按钮；输入区的麦克风按钮同样会开始准备：模型缺失时按下它会安装模型，并打开该区块显示运行状态。单独打开该区块不会开始任何下载。下载来源仍由现有的 Host 准备调用选择。检查完成或准备失败后，即使清理回调尚未运行，也允许新的准备请求接手，因此重试能够启动。准备期间，该行显示状态文字，以及一条与账户页额度条同样构造的铺满宽度的进度条：8px 高的轨道、4px 圆角、平台背景色，按已下载百分比以成功色填充。区块标题为「语音」，听写作为当前用途写在简介中。

## Alternatives considered

**打开设置页即开始准备。** 打开面板就会在没有点击的情况下开始约 190 MB 的模型下载，只想查看该设置的用户无法拒绝，而且下载结果会在他们看到开始之前就已出现。

**保留手动下载来源选择器。** Host 已负责选择来源和失败后的备用来源，因此这些控件只增加操作，而没有必要的用户选择。

**展示每个准备步骤。** 这有助于诊断准备失败，但会遮蔽普通用户需要知道的结果。Host 仍保留详细状态供诊断使用，而设置页面只呈现一个状态。

## Consequences

安装模型是一次明确的操作，其结果可见：已就绪，或失败并显示重试按钮与 Host 的消息。设置页面不展示来源选择、资源估算、取消操作或各个准备阶段；需要这些细节时可查看 Host 诊断信息。
