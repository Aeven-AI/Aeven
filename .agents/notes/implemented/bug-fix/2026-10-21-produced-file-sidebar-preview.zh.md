# Agent Note: 产出文件侧栏预览

Status: implemented

[English](2026-10-21-produced-file-sidebar-preview.md) | 中文

## 问题

新文件胶囊提示侧栏预览，但聊天打开器会委托 Host 默认应用。

## 决策

Files 插件拥有 `sidebarFiles.open`。产物组件在点击新文件胶囊和编辑文件行时调用它；已显示该文件的窗格获得焦点，否则新的 Files 窗格挂载后消费按会话保存的待打开路径，保留其他已打开的文件。文件读取保留工作区 Remote 的访问检查。PDF、Office、iWork、OpenDocument 以及没有侧栏查看器的其他二进制文件使用 Host 默认应用打开器，包括从资源树和搜索结果发起的打开。正文链接与桌面菜单保留各自的现有目标。

## 考虑过的替代方案

**使用聊天打开器：**它有意通过 Host 打开路径，同时服务编辑文件行与正文链接；修改它会扩大所请求的行为范围。

## 后果

新建和编辑文件共用一个表格组件；新建文件表格不显示行数。产物组件依赖 Files 插件。侧栏预览使用其现有的代码、Markdown 与图片查看器；HTML 显示源代码。请求保存在浏览器内存中，不改变会话日志。
