# Agent Note: 桌面端窗口控件的留白来自实测，而非推算

Status: implemented

[English](2026-09-30-desktop-window-controls-gutter.md) | 中文

## 问题

桌面外壳隐藏标题栏，把页面铺在 macOS 的窗口控件之下：[`trafficLightPosition`](../../../../apps/desktop/src/main.ts) 将三颗红绿灯内嵌到页面自身的左上角。有三处样式表用同一个算式为它们预留空间——`3 * 12px + 2 * 8px`，即三颗 12px 的按钮、间距 8px——而认证页面的顶栏则完全没有预留。

macOS 实际把它们画在相距 23px 的位置。从渲染后的窗口读取（macOS 26、Electron 44）：实心圆的起点正是外壳要求的 24px，三条前缘分别落在 24、47、70，因此最后一颗按钮的右缘在 84，比算式预留的 76 多出 8px。侧边栏外壳的表头行承载会话搜索，它把该控件放在恰好 76 处：正压在缩放按钮上——本笔记记录的缺陷即此。折叠态对话栏的侧栏折叠控件之所以没有压上，只是因为那一行在同样的预留之外又加了自身的页边距；而框架的窗口拖拽区则比它本要覆盖的按钮短了 8px。在 ≤640px 断点，该算式只预留 68px，因为它把收窄后的页边距也算在了里面，而控件并没有移动。

## 决定

[`--dsw-aeven-window-controls-gutter: 84px`](../../../../packages/client/ui-theme/src/styles/aeven-language.css) 拥有这一几何量：控件自身的 24px 内缩加上它们实际覆盖的 60px。它是页面常量，而不是 `--dsw-aeven-page-inset` 的函数——无论页面多窄，红绿灯都停在外壳放下的位置。

沿这条线排布的样式表都读取该 token：对话栏折叠态的预留，它让折叠控件及其后的会话操作整体位于该留白之后一个页边距处；侧边栏外壳的表头行，在同一留白上再加上自身行内边距，使搜索与折叠态对话栏的折叠控件站在同一条线上；以及框架的拖拽区，其宽度现在就是这段留白本身。

认证页面先于 token 样式表加载渲染，因此它们的顶栏（[`aeven-auth.css`](../../../../packages/client/ui-auth-aeven/src/vendor/aeven-auth.css)）在桌面标记下重述了这一合计值 108px。主题的样式表规格会拿它与 token 值对照断言，二者不会走散。

## 备选方案

**在外壳中重新测量，并把值注入页面。** 主进程本可以把一个自定义属性交给页面，从而任何样式表都不必持有数字。否决：Electron 的 `trafficLightPosition` 是只写的，没有可读回的测量值——它仍会是一个常量，只是离消费它的 CSS 更远一层，而且认证顶栏在任何我们自己的脚本运行之前就已绘制。

**就地修正四处样式表中的同一个算式。** 改动最小。否决：同一个算式的四份副本、其中一份还落在读不到 token 的样式表里，正是数值与绘制彼此走散的原因。token 让这个数字只有一个归属，而认证顶栏的那次重述是规格唯一盯防的例外。

**只给侧边栏表头补上缺的 8px。** 否决：认证顶栏的返回控件与品牌标记出于同样的原因压在同样的按钮之下，拖拽区也同样短了一截。这段留白是关于窗口的一个事实，三个样式表问同一个问题，就该得到一个答案。

**预留一个整数余量，而不是实测值。** 96px 或 100px 在任何 macOS 上都不会压上。否决：一个不回应任何依据的布局数字，既没有告诉后来的读者它覆盖了什么，也没有告诉他们它何时不再覆盖。实测只需一张原生截图就能重做，本笔记记录了方法。

## 后果

会话搜索从 76px 移到 108px；登录与注册页面的返回控件和品牌标记从 24px 移到同一位置；折叠态对话栏的折叠控件及其后的会话操作从 100px 移到 108px；框架拖拽区从 76px 加宽到控件的整段 84px 留白，且仍在相邻控件前一个页边距处止步。以上每个位置现在都是同一个数值加上该行自身的页边距，且在任何宽度下都成立。

这个数字记录的是 macOS 如何绘制，而非由外壳的 `WINDOW_BUTTON_SIZE` 推得：若某个 macOS 或 Electron 版本改变按钮排布，就重新实测，留白 token 随之移动。

## 测试

[`packages/client/ui-theme/tests/aeven-language-styles.client.spec.ts`](../../../../packages/client/ui-theme/tests/aeven-language-styles.client.spec.ts) 断言 token 的取值、三处消费样式表读取它而非重述算式，以及认证顶栏的字面量等于留白加页边距。

几何量本身取自运行中的窗口：三颗 12px 的圆、前缘相距 23px、第一颗在 x=24、纵向跨越 y 21–35——用 `screencapture` 截取开发版应用的窗口，再在 PNG 中量取实心圆所在的列，并通过渲染进程的调试端口读取控件矩形做对照。照同样的方式重做，读回的状态是 `getComputedStyle(...).paddingLeft` 与该线上控件的矩形。
