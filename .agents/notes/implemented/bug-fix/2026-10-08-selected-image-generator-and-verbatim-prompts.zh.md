# Agent Note: 所选图像生成器保留用户提供的提示词

Status: implemented

[English](2026-10-08-selected-image-generator-and-verbatim-prompts.md) | 中文

## 问题

随包交付的 agent 将常规图像生成器和订阅专属工具都放在仅列名称的延迟工具索引之后。照片编辑请求未检查常规生成器便选择 Codex，猜测附件标识符，并在后端超时后重试。最终调用常规生成器时又扩写用户的提示词并覆盖所选模型。

## 决策

随包交付的 `aeven` 组装从首次请求起提供 `generate_image`。常驻指令要求使用所选模型，除非用户请求其他模型；原样传递用户提供的图像提示词；通过规范化副本路径直接传入上传的参考图像，无需复制。订阅专属工具要求用户明确请求对应提供方。每次请求仅生成一次，再次生成需要用户请求。图像工具描述也要求保留用户提供的提示词，附件说明仅在修改文件本身时要求复制。生成失败后直接报告，不自动重试或检查仓库，除非用户请求调试。

## 考虑过的替代方案

**删除订阅图像能力。** 这些提供方仍可通过常规生成器选择，也可在用户明确请求时直接调用；删除它们超出路由修正的范围。

**仅修改工具描述。** 延迟加载的描述无法指导模型从仅列名称的索引中做出初始选择。常规生成器在发现工具前即可见，常驻指令负责指导选择。

## 后果

首次请求多携带一个工具 schema。提示词保留和路由选择依赖模型遵循常驻指令；提供方和工具执行器保持不变。图像渲染器仍通过现有调用与结果事件结束加载。
