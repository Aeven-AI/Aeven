# Agent Note：在桌面设备上输入的内容就在该桌面设备上运行

Status: implemented

[English](2026-11-18-forwarded-input-waited-for-an-unreachable-cloud.md) | 中文

## 问题

2026-11-18，一位桌面用户在某个对话中的消息显示“Ævening…”，没有停止按钮，刷新后消失。中转服务器显示，桌面设备在 07:38:26 和 07:51:45 把它们写入同步收件箱，发给托管 Host。该 Host 自 2026-11-16 起就没有同步过这个账户（账户密钥受通行密钥保护，而 Host 没有授权），因此从未看到它们。它在 07:53:31 取走了所有排队的输入，此时距用户打开 Aeven Web、Host 获得授权仅 1.6 秒。

两条规则造成了这次等待。`homeOf` 只要始终在线设备运行了对话的最近一回合，就把对话留在它上面（这是 2026-11-10 的规则，让云端把对话连同其文件和后台任务一起保留）；同一天的桌面优先路由只覆盖在 Aeven Web 上输入的内容。`consumePass` 在账户有始终在线设备时，从不让打字的桌面设备运行它转发出去的输入，既没有超时也没有过期。

## 决定

- 在桌面设备上输入的内容就在该桌面设备上运行。在桌面设备上，`homeOf` 不再指出始终在线的编写方；桌面设备接管该对话。对话被移到的另一台桌面设备在线时，它仍然指出那台设备；而正在另一台设备上运行的回合，其输入仍发给该运行方。
- 当输入被发往的设备没有接手时，输入所在的设备在 `remoteFallbackMs`（10 秒）之后自己运行它，无论账户是否有始终在线设备。由运行方租约来仲裁目标设备迟到的接手。

## 考虑过的替代方案

- **在云端能访问账户时，把云端的对话留在云端。** 被所有者否决：在桌面设备上输入就在那里运行。
- **让转发的输入过期。** 已否决：消息仍然不会运行，只是之后再消失。

## 影响

如果对话的回合使用了只存在于账户云端文件夹中的文件，在它们同步之前，桌面设备上运行时没有这些文件。此改动之前构建的桌面设备仍会转发给始终在线设备。运行中途失去其设备的回合是另一项工作。
