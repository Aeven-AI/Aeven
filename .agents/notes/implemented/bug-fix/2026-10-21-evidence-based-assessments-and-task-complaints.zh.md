# Agent Note: 基于证据的评估与任务抱怨

Status: implemented

[English](2026-10-21-evidence-based-assessments-and-task-complaints.md) | 中文

## Problem

对产品比较的抱怨触发了个人支持行为、无关个人历史的召回以及缺乏依据的安慰。竞争产品的营销声明在已存事实中变成了已验证的能力和战略结论。轮次级纠正还取代了前一轮次独立记住的全部事实。

## Decision

Aeven 人设不受语气影响，始终以同事角色处理任务抱怨。比较区分广告声明、已检查的实现、已演示的行为、计划和评估，并采用相同的证据标准。纠正修改有争议的声明及其后果，同时保留有依据的结论。记忆写入指令和捕获摘要保留归属、日期及不确定性；单条写入接受批量工具的知识分类。

现有的[召回判定](../../../../packages/memory/memory-memos/README.zh.md)检查每种候选中的个人内容，包括经验片段。对助手生气并不等于分享个人生活。个人支持请求仍保留相关的个人召回。

只有明确的事实替代判定才会取代前一次往来。短语检测保留为结果证据，不作为使记忆失效的依据。关于对话的判定不会取代其中独立记住的事实；错误事实需要显式编辑或忘记。

## Alternatives considered

要求偏向 Aeven 的指令会用赞扬替代负面偏见。仅过滤 person 领域的记忆会遗漏片段中的个人历史。取代整批事实假设每条已存事实都表达了有争议的声明。新的置信度结构需要修改持久格式，却无法证明模型评估是否正确。

## Consequences

存储格式和会话事件格式不变。提示指导减少缺乏依据的判断，但不能证明模型遵守要求。录制的 headless 场景固定随包交付的人设和记忆 schema，并通过独立工作区结果验证知识写入。定向捕获测试覆盖事实替代、抱怨及独立批量事实的保留；相关性和评估行为仍需实时模型检查。已存历史评估需要定向审计，不能在召回时被升级为事实。
