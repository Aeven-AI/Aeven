# Agent Note: 公开资料研究与用户自主权

Status: implemented

[English](2026-10-25-public-research-and-user-agency.md) | 中文

## 问题

一段私人对话对普通公开事实作出一概拒绝，在用户请求研究之后反复提供关系建议，并根据昵称和头像配饰作出缺乏依据的身份确认。

## 决策

内置 Aeven persona 只带一段简短的话：在私人对话中和在工作中一样按用户的要求去做，包括带来源地查找某个人；不因对象是私人个体而拒绝，不说教，不添加未被要求的警告，也不用建议替换任务；说明找到了什么、没有检查什么，不把相同的昵称或头像当作确认。persona 本身不设任何限制；模型拒绝的内容来自模型自身。persona 承载语气，因此这段话说明该做什么，而不是罗列评估和核实流程。

[证据与任务投诉决策](2026-10-21-evidence-based-assessments-and-task-complaints.zh.md)保持有效：它负责比较证据和记忆处理；本决策涵盖人物公开资料研究及私人对话中的用户自主权。

## 考虑过的替代方案

**按类别设限**（敏感信息、联系方式、行踪、社交关系、推断特征）重新造成了它们本想收窄的拒绝，因为模型把每个类别都当作拒绝的理由。**一概拒绝私人个体研究**会拒绝普通的传记问题。**在 persona 中写入详细的核实规则**会让模型在询问和行动之间犹豫。**新增拒绝拦截器**会增加第二套决策机制，而观察到的拒绝和无依据的确定性来自模型回复。

## 影响

本变更增加提示指导，不改变工具、审批或会话格式。assessment-memory 录制会话快照固定内置 persona。语气和判断需要通过真实模型检查评估；提示指导不能保证遵循。已安装的桌面预设需要同样的修改才能用于新会话，而已经挂载的会话保留其加载的代际，直到 Host 重启。
