# Agent Note: 侧栏工具需要会话窗口确认打开

Status: implemented

[English](2026-10-24-session-sidebar-open-acknowledgement.md) | 中文

## 问题

模型打开 shell 或文件时，需要让用户在对话旁看到它。仅创建终端或解析路径，无法证明某个窗口已显示它。

## 决策

`terminal/show` 和 `workspace-files/show` 请求显示调用会话的窗口打开指定侧栏内容。远程事件桥传递请求及其确认。每个调用方通过配置的超时和取消信号限制等待时间。没有窗口确认的终端会被关闭；文件请求则报告没有窗口显示它。

## 考虑过的替代方案

**分配资源后直接返回成功。** 分配只能建立 shell 或路径，无法向模型证明用户看得到它。

**让用户每次手动打开面板。** 这使模型无法通过现有侧栏完成显示文件或终端的请求。

## 影响

打开操作依赖已连接且显示该会话的窗口。无界面会话不能声称成功，显示请求失败后也不会留下不可见的运行中终端。工具保留现有的会话归属与文件系统访问检查。
