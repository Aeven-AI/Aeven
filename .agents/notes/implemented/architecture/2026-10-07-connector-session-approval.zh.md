# Agent Note: 连接器操作预览与限定范围的会话审批

Status: implemented

[English](2026-10-07-connector-session-approval.md) | 中文

## Problem

连接器写入需要在同意前显示可读内容。重复审批不得授权其他账户、其他操作或分叉会话。

## Decision

审批预览从关联的已记录工具调用派生，包括嵌套调用。先显示目标和消息内容，再显示其余参数；工具参数不复制到审批请求中。预览使用接管面板自身的字体——整张卡片同一字号、行高和字体族——字段标签仅以 500 字重区分，绝不用浏览器的粗体。只有关联的命令保留代码字体族。

请求方提供账户和操作范围。连接器范围包含账户专属工具名称；Google Workspace 原始调用范围还包含服务及资源方法路径。审批服务在决定事件中提交范围和原会话 ID，并向消费方返回现有的一次性结果。取消和 never 策略优先。分叉不能复用其他会话 ID 的授权。

## Alternatives considered

全局会话允许策略会混合无关账户、shell 提权和连接器管理。仅由客户端记住决定会绕过持久的 Host 执行。

## Consequences

重复操作可以使用不同收件人和内容；面板在同意前解释这一点。会话授权在会话重载后保留，没有撤销界面。除非工具调用包含草稿实际内容，否则草稿标识符仍仅显示标识符。按用户明确要求不添加自动化测试和快照更新；验证使用 TypeScript、构建及手动运行验证。
