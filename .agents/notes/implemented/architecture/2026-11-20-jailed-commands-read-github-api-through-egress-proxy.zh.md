# Agent Note：监狱中的命令经 egress 代理只读 GitHub API，从不写入

Status: implemented

[English](2026-11-20-jailed-commands-read-github-api-through-egress-proxy.md) | 中文

## 问题

在 Aeven Cloud 上，监狱中的命令只能通过 Git 访问 GitHub：egress 代理用账户的凭据把 smart HTTP 转发到 `github.com`，并在有风险的推送之前询问用户。`api.github.com` 不在允许列表中，而隧道无法携带监狱不得持有的凭据，因此 `gh`、`watch-pr` 以及每个读取拉取请求状态的剧本在那里都会失败。

## 决定

`egress.githubApi: { requestsPerHour }` 为代理增加一条只读的 GitHub API 路由。当 `GH_HOST` 为 `github.localhost` 时，`gh` 使用明文 HTTP，因此镜像中的 `gh` 包装脚本设置该主机和一个占位令牌，代理把每个发往 `api.github.localhost` 的请求转发到 `https://api.github.com/`，并以账户的 `github.com` 凭据替换请求所携带的任何凭据。只有 `/graphql` 以外的 REST `GET` 与 `HEAD`，以及文档中只含查询与片段的 `POST /graphql` 能够通过；其他任何方法、变更、订阅、`GET /graphql`，以及经过压缩或过大的 GraphQL 请求体，都在到达 GitHub 之前被拒绝。只转发允许列表中的请求头，因此任何方法覆盖头都不会到达 GitHub。每个账户每个整点小时最多发出 `requestsPerHour` 个请求；托管 Aeven 设为 1000。

## 安全分析

**写入。** 开放整个 API 会让监狱中的代码在无需批准的情况下用用户的令牌合并、删除、评论或创建 gist，绕过代理执行的推送批准，因此该路由只读。其他地方的只读 GraphQL 代理曾被绕过：它们用正则表达式检测，漏掉了位于片段、逗号、字节顺序标记、`#` 注释之后的 `mutation`，或块字符串中被转义的 `"""` 所隐藏的变更。本代理改为按 GraphQL 词法语法切分文档，拒绝语法之外的任何字符或记号，并以嵌套深度为零处的第一个记号为每个定义分类。以 `graphql-js` 16.9 为参照，对已公开的绕过形式、拼接到有效查询每个位置的变更以及一百万个随机记号序列进行差分测试，没有发现代理接受而解析结果并非仅含查询与片段的文档，也没有发现被拒绝的有效查询；代理接受而 `graphql-js` 拒绝的 113 个文档都是 GitHub 同样会拒绝的语法错误。

**凭据。** 令牌只从提供方传到代理，再在代理的地址检查下传到 `api.github.com`。重定向被原样返回而不是由代理跟随，指向 `api.github.com` 的地址会改写回该路由，因此令牌从不到达其他主机；转发的响应头不携带凭据。

**读取。** 该路由能读取账户令牌可读的一切，范围比 GitHub 连接器的工具集更宽，例如仓库的 Actions 变量和用户的私有 gist。这些数据只进入账户自己的对话。要把它们带出去需要写入通道，而监狱的写入通道只有需要批准的推送，以及允许列表中的软件包与下载主机，后者不接受来自监狱的凭据。评审文本与 issue 正文对模型而言是不受信任的输入，这在连接器工具中已经如此；`watch-pr` 会去除其中的控制字符。

**速率限制。** 循环可能耗尽账户与其连接器工具共享的每小时 5000 次请求，因此由每账户的预算加以约束。

## 考虑过的替代方案

**完整 API 加逐请求批准。** 代理已能在对话中询问，但逐个批准原始 API 调用会让用户面对无法判断的请求；连接器工具把写入呈现为带有自身批准的操作。

**为 `api.github.com` 做 TLS 拦截的代理。** `gh` 将不需要包装脚本，但每个监狱都要信任一个密钥存放在宿主上的本地证书颁发机构，所有经隧道的主机都会变得可被拦截。

**把令牌传入监狱。** 一个环境变量就能让 `gh` 工作，但监狱中的任何命令、软件包脚本或被注入的指令都可以使用或外泄该凭据，而 Git 路由正是为防止这一点而建。

## 影响

监狱中的 `gh` 需要 `--repo owner/name`，因为那里的 Git 远程地址指向代理。被拒绝的写入以 `403` 及原因作答，没有 GitHub 连接的账户得到 `401`。该路由依赖 `gh` 对 `github.localhost` 的明文 HTTP 处理；若某个 `gh` 版本移除此行为，路由会明显失效，而不是悄无声息地失效。
