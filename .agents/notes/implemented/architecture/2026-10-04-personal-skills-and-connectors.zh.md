# Agent Note: 个人技能和连接器

Status: implemented

[English](2026-10-04-personal-skills-and-connectors.md) | 中文

## Decision

[账户集成主机](../../../../packages/host/account-integrations/README.zh.md)从已认证请求确定每项管理操作的所属账户。浏览器请求不能选择账户。个人技能发现使用对话持久化的所属账户；连接器凭据由账户和连接器身份寻址。连接器工具注册在所属 agent 的 scope，其生命周期同时由集成插件和对话拥有。即使旧工具目录仍可见，执行器也会拒绝已禁用、已删除或属于其他账户的连接。

## Provider applications

自定义 Streamable HTTP MCP 连接和 GitHub 个人访问令牌使用现有 MCP 工具发现。Google 服务共享部署所属的 OAuth 应用，并使用维护中的 Google Workspace MCP 桥接及 OpenAI 插件发布的按服务区分授权权限。技能包保留上游内容；可用操作由 MCP 服务器实际发现的工具决定。Microsoft 365 和 GitHub OAuth 登录需要部署所属的应用注册及兼容 MCP 资源。授权 state 捕获发起账户和 PKCE verifier，有时限且只能消费一次。回调不会从浏览器当前登录状态推导归属。凭据提供方串行执行刷新操作，且不会通过管理 Remote 返回已保存秘密。

## Connector skill ownership

连接器元数据声明各提供方所属的已安装技能定义。设置通过现有注册表解析指令正文，不维护第二套技能库。Google 云端硬盘拥有六项文档及文件技能，包含表单；Gmail、日历和 GitHub 各有简洁的连接器专用指令。连接器技能按名称仅在连接器详情中显示一次，并通过可关闭的弹窗展示指令。技能调用跟随已启用且已授权的连接；单独的账户技能偏好不适用。断开或禁用连接会使技能目录失效并卸载工具，执行器仍拒绝过期调用。禁用保留凭据。设置观察现有技能变更通知以刷新 OAuth 完成及连接操作，并丢弃已被替代的列表响应。断开连接取消待处理授权，并在删除已保存状态前等待正在执行的回调。连接状态表示已保存授权，不代表持续监测服务器可达性。Forms API 的 `forms.create` 和 `forms.batchUpdate` 遵循普通文档编辑权限处理，与精选 Sheets 和 Docs 编辑一致。其他原始 Google 写入仍须显式批准。

## Skill resources

设置从已认证账户确定技能库归属，通过现有技能注册表读取个人导入、部署默认预设 scope 及该账户所属的每个文件夹工作区。Remote 不接受对话 ID，浏览器不读取所选对话状态。工作区定义展示在技能库中，但调用仍限制在所属工作区。预设和文件系统技能文件由其来源管理；只有账户导入支持移除。账户偏好按技能名称跨来源持久化。可撤销的注册表调用策略在禁用时将两种调用权限设为 false，并应用于目录观察和定义加载，包括已缓存候选项。禁用技能仍可查看。启用偏好不改变来源的调用权限，也不扩大工作区访问权限。

导入验证归档大小、相对资源路径、元数据和调用控制。账户 domain 是技能包内容的权威来源；加载技能时生成私有资源目录。移除目录项不会擦除已经生成的资源文件。注册表失效也会清空浏览器斜杠菜单目录。专有 Claude 文档包和提取的应用二进制文件不参与重新分发。

## Verification scope

用户要求仅进行 TypeScript 编译及构建，不运行测试套件。提供方授权需要 OAuth 注册和用户授权；构建成功不能证明提供方登录成功。现有身份、技能调用和 MCP 生命周期笔记保留其独立范围；此决策不取代它们。
