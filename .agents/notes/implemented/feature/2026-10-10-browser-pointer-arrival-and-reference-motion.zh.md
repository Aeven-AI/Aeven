# Agent Note: 浏览器指针到达与参考运动

Status: implemented

[English](2026-10-10-browser-pointer-arrival-and-reference-motion.md) | 中文

## Problem

浏览器输入可能在可见指针到达前生效。固定二次曲线、未使用的伸缩变换、重复空闲摆动和虚拟滚动漂移均与提取出的 Codex 桌面指针不同。Electron 对后台渲染节流时，无限等待到达会停滞，见[面板指针决策](2026-10-01-sidebar-browser-agent-pointer.zh.md)。

## Decision

离散 guest 输入等待所属应用渲染器发出的编号确认，最长 1500 毫秒。隐藏面板立即确认。取消会释放等待并阻止排队的工具栏操作。面板直接执行导航和历史控件前，也等待同一个 overlay 到达方法。

长距离路径根据边界和平滑度，从 20 条三次曲线和分段弧线中选择，路径指标决定时序。短距离滑动、纵向伸缩、补偿图像旋转、可见性模糊和有限空闲摆动遵循参考实现。布局修正直接定位，不启动路径；滚动既不等待到达，也不添加指针漂移。

## Alternatives considered

**无限等待渲染器到达。** 后台节流可能阻止推进，因此到达等待有固定上限。

**立即输入，再绘制指针。** 页面反应与可见指针脱节。

**调整二次曲线参数。** 这仍缺少参考实现的候选选择、接近方向和依路径变化的时序。

## Consequences

Electron 预加载与面板共享指针确认和取消消息。面板保留 portal、控件查找和仅绘制指针的呈现方式。构建与 TypeScript 证据不能证明逐帧视觉一致；根据要求限定的验证范围，实时渲染尚未验证。
