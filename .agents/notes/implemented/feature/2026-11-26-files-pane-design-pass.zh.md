# Agent Note: Files pane design pass

Status: implemented

[English](2026-11-26-files-pane-design-pass.md) | 中文

## Problem

议题 #810 发现，右侧栏的文件面板（[`@aeven/client-ui-sidebar-files`](../../../../packages/client/ui-sidebar-files/README.zh.md)）在打开文件后表现不一致。文件与停靠的文件树之间隔着 4px 的空隙；没有左右内边距的 HTML 预览直接贴到这条空隙，而文本视图保留 24px。停靠区宽度固定。文件栏下方的第二条栏在预览与复制控件旁重复显示文件扩展名，文件栏与工具栏上的后退、前进与全部折叠控件效果难以预料。图标按钮只有原生 `title` 提示。

## Decision

- **分栏间距。** 分栏没有空隙。在停靠的文件树旁，文件栏与文本正文右侧保留 16px，渲染后的页面在距文件树 16px 处结束，因此切换视图时文件栏控件与文件树都不移动。
- **可调宽度的停靠区。** 这条 16px 线上的零宽拖动条可拖动停靠区宽度，左右方向键每次调整 16px。宽度与资源管理器的其他状态一样按会话与标签页记住。`FilesPane.tsx` 中的 `DOCK_FLOOR`（240px）与 `FILE_FLOOR`（380px）同时限定拖动与 CSS 宽度，两者之和是文件树开始停靠的窗格宽度。拖动条在悬停、聚焦与拖动时显示与对话宽度手柄相同的 1px 线。
- **单一文件栏。** 扩展名与复制栏被移除。HTML 视图切换按钮位于文件栏中，显示按下后将切换到的视图：源代码视图下为 lucide `tv-minimal-play`，渲染页面下为 `code`。关闭按钮位于文件栏最前，其图标与上方 Files 标签页图标对齐。
- **移除的控件。** 后退、前进及其背后的文件历史，以及全部折叠，均被移除；文件夹仍可逐个折叠。
- **提示。** 面板中的每个图标按钮都改用共享的 `Tooltip` 组件，而不是原生 `title`。
- **加载。** 正在加载的文件夹、搜索、文件或页面渲染显示默认尺寸的共享 `Spinner`，取代加载文字；该文字作为状态的无障碍标签。

## Alternatives considered

**在渲染页面旁给停靠区加 16px 内边距**被否决：每次切换视图时文件树的内容都会移动。**改为将停靠区加宽 16px** 让文件树保持不动，但文件栏控件会移动。**以文件树边缘为中心的拖动手柄**被否决，因为其点击区域覆盖了文件树的搜索框，且线条不在预览边缘上。**保留文件历史但去掉按钮**被否决，因为没有其他地方读取它。

## Consequences

拖动后的停靠区宽度在重新加载后恢复默认，与已展开的文件夹相同。面板不再提供复制文件控件；下载与“打开方式”仍然保留。从文件树打开的文件只能通过再次打开来回到之前的文件。
