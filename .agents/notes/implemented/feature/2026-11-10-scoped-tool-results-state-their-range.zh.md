# Agent Note: 有范围的工具结果说明自己的范围

Status: implemented

[English](2026-11-10-scoped-tool-results-state-their-range.md) | 中文

## 问题

空的日历列表只证明那一个日历上的那一个时间窗口没有事件。结果里没有任何说明，于是一条回复曾在没有查询的情况下说后一天是空的（#554）。这次失误中记忆指导的那一半已在 `memory-context` 修复；结果本身读起来仍比它的查询范围更宽。

## 决策

`mcp-client` 新增 `resultNotes`：按原始工具名，在每个成功结果后追加一段说明，`{arg}` 和 `{arg|fallback}` 由调用参数填充。Google 日历连接器为 `calendar_list_events` 注册了一段说明，写明时间窗口、日历和当前页，并说明该列表不覆盖其他任何内容。说明随结果一起传递，因此在每个对话、模型和人设中都成立，部署也可以在配置中为其他有范围的工具添加说明。

## 考虑过的替代方案

**在人设或系统提示词中加规则。** 否决：行为修复属于负责该行为的插件，而且通用规则要和其他所有指令竞争，而说明就放在它所限定的那个结果旁边。

**修改第三方的 Workspace MCP 服务器。** 否决：它是一个依赖，而投影层正是 Aeven 已经为模型调整 MCP 结果的地方。

## 后果

每个日历列表多出一句话。结果由参数限定范围的连接器无需写代码就能说明自己的范围。

## 验证

问某一天的日历时，会话的工具结果中列表后面会出现这段说明，写明那一天的时间窗口和所查询的日历。
