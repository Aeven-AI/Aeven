# Agent Note: 召回可靠性与一次性退出时的采集

Status: implemented

[English](2026-10-01-memory-recall-and-capture.md) | 中文

## Problem

三个缺陷让一个回合携带的记忆少于系统表面上交付的量，而三者都无法从回合本身看出来。

MemOS 会把查询中的长标识符当作硬性资格过滤器，只保留逐字包含它的候选。回合起始查询是主题查询，因此用户消息中只要出现一个标识符形状的词元——会话 id、提交哈希，或 `recalled-context` 这类普通的连字符复合词——就会丢弃全部候选并返回空。在 MemOS 已记录的 45 次回合起始检索中，**7 次带有标识符，全部 7 次都丢失了候选，其中 5 次完全没有返回结果**；而不带标识符的 38 次全部返回 8–20 条命中。

没有收到记忆的回合，看起来与从未执行召回的回合完全相同：结果只进入一行 `logger.debug`，而正在运行的 Host 标准输出日志是空的。

一次性驱动在 `session/settle` 解析后立即退出，而 `memory-context` 并未订阅它，因此无头回合排队的采集在进程退出时被丢弃。基准测试测得 `traces 0→0`：教学会话结束了，什么也没有存下。

## Decision

`@aeven/memory-memos` 先按原样执行回合起始查询；当它没有任何可见命中、且查询含有核心会逐字确认的词元时，在同一截止时间内重试一次，并去掉这些词元。`src/query.ts` 复刻核心的判定规则，使普通长词在重试中得以保留。显式搜索保留标识符，因为在显式搜索里标识符正是要点。

当回合起始召回未交付任何块时，`@aeven/memory-context` 追加一行记录在案的 `notice`，说明属于哪种情况：召回超时、未找到，或失败。因此该回合会记录自己是在没有记忆的情况下运行的，而不再显得一切正常。

`@aeven/memory-context` 还会在 `session/settle` 排空该会话已排队的采集，因为那正是一次性驱动在退出前等待的检查点。provider 的关闭运行在它已接受的一切之后，而活动会话永远不会到达该检查点。

## Alternatives considered

- 修改 MemOS 核心中的标识符规则。该规则属于上游，且对标识符查找是正确的；部署方拥有的是自己的查询，而不是引擎。
- 始终从回合起始查询中移除标识符。已存的轨迹可能包含用户粘贴的那个标识符，因此先尝试精确的那一遍，主题重试只挽救空结果。
- 只用 logger 报告空召回。logger 不是该回合的记录，于是空召回与失败召回都无法与“从未召回”区分开。
- 在 `session/disposed` 排空采集。销毁运行在一次性驱动退出前不会到达的路径上，这正是队列丢失的原因。

## Consequences

只有在查询带有标识符且精确那一遍没有返回结果时，回合起始召回才会多花一次 provider 调用；重试共用原本的截止时间，因此 `recallTimeoutMs` 仍然约束该回合。

没有记忆的回合会多出一行 notice，约 100 个字符，模型由此能判断自己是在缺少早前上下文的情况下作答。未被度量的能力仍然未被度量：notice 报告的是交付，而不是遵从。

目前只有无头驱动会到达 `session/settle`，因此在 GUI 中该排空不起作用，那里的 `session/disposed` 已经关闭会话。

## Verification

TypeScript 与完整构建通过。针对真实记忆数据库，使用 MemOS 在 11:40:44 记录的那条确切查询，以及一条新的带标识符查询：按原样执行的查询返回 0 条命中，去掉标识符词元的同一查询返回 5 条，而 `MemosMemory.recall` 对原查询返回 5 条且 `timedOut=false`。在重建后的 Host 上，一个携带 `b1a6bc0e477c43649bf966…` 的 GUI 回合收到了 828 字符的召回块，而修复前的构建什么也没有收到。

同一变更中加入的基准测试直接度量了采集缺陷：在 `session/settle` 排空之前，一次教学运行报告 `traces 0→0`，探针弃答；之后为 `traces 0→1`，探针返回了所教的值。

有两项主张是刻意不提出的。召回交付已被确立；召回收益则没有，并且有一个实测回合显示块已交付，而 agent 把整个回合用在了无关的工具调用上。`@aeven/memory-memos` 复刻了上游的判定规则，而该规则可能在本包之外变化：一次改变标识符抽取的核心升级会悄然让重试失效，而目前没有任何东西会在那时失败。
