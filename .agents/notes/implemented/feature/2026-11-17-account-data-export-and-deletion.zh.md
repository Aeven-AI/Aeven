# Agent Note：账户数据导出与删除

Status: implemented

[English](2026-11-17-account-data-export-and-deletion.md) | 中文

## 问题

用户无法获取自己 Aeven 数据的副本，也无法删除账户，而 GDPR 要求两者（第 15、17 和 20 条）。用户数据分散在 Aeven API（账户、方案、钱包、用量、连接器、同步中继、文件云）以及为其服务过的每个 Host 上：会话记录、附件、记忆、录音、偏好、Aeven 文件夹、连接器存储。

## 决定

“设置 → 账户”以“你的数据”分组结尾：先是“导出数据”，然后“删除账户”作为页面最后一行。每行有一行描述和一个问号图标，点开显示详细说明。

**导出。** `@aeven/host-account-data` 在页面所连接的 Host 上通过 `GET /api/account-data/export` 流式输出 zip：桌面应用对应桌面 Host，Aeven Web 对应托管 Host。响应立即开始，归档边读边写，因此无论大小，本地导出都在毫秒内开始；2026-11-17，一个真实账户的 1.8 GB 导出（1,292 个聊天、3,711 个附件、45,561 条记忆）在 41 秒内完成，Host 堆内存保持平稳。每个保存按账户数据的插件注册一个 `AccountDataSource`，负责导出和清除一个账户。Aeven API 上的副本使用用户自己的令牌从 `GET /api/account/export` 获取。密码、令牌和密钥材料从不进入导出。

**删除。** Aeven API 的 `POST /api/account/delete` 需要再次输入账户邮箱，开启双重验证时还需要身份验证器验证码或恢复码。它立即停用账户：所有会话退出登录，生效中的方案设为在当期结束时终止，除 `/api/account` 外的所有 API 都拒绝该账户。30 天宽限期内登录只会看到恢复界面；恢复会继续方案。宽限期结束后，每小时运行的任务彻底删除该账户及其所有记录，立即取消方案，删除文件云和上传文件，只留下保存 `sha256(userId)` 的墓碑。Host 以该摘要命名每个账户的主目录，因此每个 Host 向 `POST /api/account/deleted` 询问它持有的账户，并清除已彻底删除的账户。

**托管限制。** 每个账户一次只进行一个导出。托管包允许跨账户同时两个导出，每个上限 25 MB/s；导出在内存中只保留一个数据块和至多一份聊天记录。

## 考虑过的替代方案

- **立即删除。** 所有者选择了 30 天宽限期，登录即可恢复。
- **由服务器生成导出并通过邮件发送链接。** 拒绝：可读数据在设备上，服务器只保存加密的同步帧，而且所有者希望下载立即开始。
- **fflate 的流式 `Zip`。** 拒绝：它不支持写入 ZIP64，而真实账户会超过 4 GiB。`yazl` 支持背压流式写入，并自动切换到 ZIP64。
- **一个通用的存储单元数据源。** 拒绝：存储域由各插件用类型化规格打开，因此由拥有数据的插件各自注册数据源。

## 影响

删除时剩余的已购额度作废，对话框会说明；Stripe 保留付款记录。再也不上线的 Host 会保留该账户的本地数据。会话恢复副本不归属于任何账户，会被保留。
