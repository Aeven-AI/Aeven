# Agent Note：回复中的视频，以及来自选定文章的新闻卡片

Status: implemented

[English](2026-10-13-videos-in-a-reply-and-news-cards-from-articles.md) | 中文

## 问题

“演示一下标准的卧推怎么做”这类请求只能得到文字回答，最多附一个 YouTube 链接，读者必须离开对话才能观看。回复里没有任何东西能播放视频。

前一天加入的新闻卡片能够渲染，但一次真实的“最新科技新闻”运行暴露了四个缺陷。调用指定了英语，卡片却以越南语和保加利亚语出现：所有请求与翻译共用一个 20 秒期限，搜索与下载耗尽了它，翻译被取消后静默保留了原文。带重音的文字显示为原始实体（`Truy&ecirc;̀n`），因为解码器只认识 13 个命名引用。模型为每则新闻各搜索一次、数量为三，于是同一则新闻以三种语言出现三次，而且卡片是搜索命中结果，而不是回复所讲的那些文章。同批调用依次执行，因为该工具从未声明可并行，整轮因此耗时四分半。

回复流式输出时，一行图片或视频还会断成两段：空行会在最后一个段落分隔处关闭流式区块，停顿之后到达的图片于是开始新的区块和新的一行。

## 决定

**视频就地播放。** Markdown 引擎把每个 YouTube 或 Vimeo 链接变成播放器。只包含视频链接的段落直接变成播放器，连续的一组构成一个 `div.markdown-video-grid`，由宿主像一行图片那样排布：一个视频占满整栏，两个平分，三个各占三分之一。写在句子里的视频保留链接，提到它的段落之后跟上它的播放器。每个播放器先显示提供方的封面与播放按钮，按下后才加载提供方的内嵌页面，因此列出多个视频的回复、以及之后每次重放的对话记录，加载的都是静态图而不是播放器。内嵌地址由视频 id 重新构造（YouTube 走 `youtube-nocookie.com`，Vimeo 带 `dnt=1`），从不取自链接本身。图块带 30px 圆角。

所有图块均为 3:2，封面与播放器相同，一行因此读作一条整齐的带，视频开始播放时也没有任何东西移动；其他形状的视频在图块内以黑边播放。Vimeo 的封面来自其 oEmbed 查询，YouTube 的封面由 id 得出。封面加载完成前，图块显示与图片图块相同的加载底面。

`aeven` preset 告诉模型：当用户请求演示某件事怎么做或怎么动时，先搜索视频，并把链接单独放在一行；只链接搜索返回的视频。

桌面应用为 YouTube 播放器的页面请求提供网页 referrer，因为对 `avn-app://` 页面，YouTube 会拒绝播放（错误 153）。

**流式输出时保持媒体连续段未关闭。** 空行之前的段落是图片或视频行时，区块保持打开，直到下一段落表明连续段是否继续，因此无论流的节奏如何，一组媒体都渲染为一行。

**新闻卡片来自模型选定的文章。** `find_images` 在 `cards` 布局下接受 `urls`：每篇文章一张卡片，顺序与回复呈现的顺序一致，各页面并行抓取。preset 告诉模型每次回答只发起一次这样的调用，并且不要再以链接列出这些新闻。每个请求都有自己的期限，翻译有独立的 `translationTimeoutMs`。文字用 `entities` 包解码，并在句子或完整单词处截断。开头文字跳过图片署名与关注提示。该工具声明可与同批调用并行。客户端从解析后的参数读取布局。

## 考虑过的替代方案

**像 `object-fit: cover` 那样裁剪播放中的视频以铺满图块。** 已实现，并在真实检查中否决：跨源播放器只能靠放大内嵌页面来裁剪，对于其他形状的视频，这会把 YouTube 的控制栏推到可见区域之外。

**让播放中的图块改成视频自身的长宽比。** 已实现，并在真实检查中否决：读者按下播放时图块会变大，看起来像页面在跳动。

**直接加载每个提供方的播放器而不显示封面。** 每次渲染和重放都要为每个视频加载一个重量级播放器，而且在读者选择观看之前，每个播放器都会向提供方报告这次观看。

**让写在正文里的视频链接保持为链接。** 这正是“演示一下”不应得到的结果；链接为句子保留，播放器加在旁边。

**流结束后重新分组。** 渲染器保留已定型的区块，而不是重新渲染整个文档，而重新渲染会让读者已经开始播放的播放器重新挂载。

## 影响

回复可以用读者就地观看的视频回答“演示一下”。回复中的任何 YouTube 或 Vimeo 链接现在都会播放，包括引用；引用很多视频的回复会显示很多封面。

桌面端的 referrer 在主进程中设置，只在网页客户端中验证过。

提示词与 `find_images` 的改动在下次 Host 启动时生效。`find_images` 仍没有测试套件，卡片开头文字靠模式规则抓取，而不是用正文提取解析器。
