# Agent Note：设置的每个分区都用共享控件绘制，导航按组归并

Status: implemented

[English](2026-10-28-settings-shared-controls-and-grouped-nav.md) | 中文

## 问题

设置有十一个导航入口，每个分区都自己绘制行、下拉胶囊、开关与标签栏，只有 `SectionHeader` 是共享的。分区样式表中有 20 种不同的圆角与 57 种不同的内边距；六个包各自绘制开关，七处绘制相同的选择胶囊，三处绘制相同的下划线标签。布尔偏好在“通用”中用开/关下拉，在“账户”中用开关。“账户”的组标题与 16px 的页面标题同样大小，“同步”的标题使用 600 字重。“语音”只为一行模型占用了一整页。

## 决定

`@aeven/client-ui-primitives` 拥有设置控件：`SettingsGroup` 与 `SettingsRow` 负责布局与字号层级（页面标题 16/500，组标题 14/500，行标题 14/400，说明 12/18 三级色），`SettingsSelect` 用于选择，`Switch` 用于布尔值，`Tabs` 的 `underline` 变体用于分区内的页面，`pill` 变体用于共享一个导航入口的分区。每个设置分区都组合这些控件，分区样式表只保留布局。面板中不出现高于 500 的字重：面板上一条零特异性的规则替换浏览器的粗体默认值。

导航有七个入口：账户、通用、连接器、记忆、提供商、扩展、个性化。外壳拥有一张分组分区 id 的表，因此“账户”包含账户与同步，“扩展”包含技能与插件；分组入口在页眉行以胶囊标签显示其成员。分区保留各自的 id，因此 `#!/settings/<section>` 地址仍会打开对应标签。“外观”与“语音输入”是“通用”中的组，以 `settings.general.item` 条目注册，开发者模式位于末尾的“高级”组。

## 考虑过的备选方案

- **在每个插槽注册上加 `group` 选项。** 它能让每个分区声明自己的组，但为一个消费者拓宽了通用插槽选项；外壳已按分区 id 拥有导航图标表。
- **五个入口，“连接”合并提供商与连接器。** 连接器是大多数读者最先设置的内容，因此保持为顶层入口。
- **在每个分区内使用胶囊标签。** 分区已为自身页面绘制下划线标签；两条下划线标签叠放会被读成同一层级。

## 后果

- 新设置组合共享控件；自行绘制开关、胶囊或标签的分区样式表重复了已解决的控件。
- 带有元素级 `button` 规则的分区样式表必须排除 `[role='switch']` 与 `[role='tab']`，否则会改写共享控件的样式。
- 对分区分组是对外壳分组表的修改，而不是对分区所在包的修改。
