# Agent Note: 多账号的托管版 Aeven Web

Status: implemented

[English](2026-11-05-hosted-web-host.md) | 中文

## 问题

Aeven Web 此前只作为单台机器上的应用运行：一个账号、自己的磁盘、所有能力全部挂载。在 Aeven 自己的基础设施上用一个 Host 服务许多人，则要把这两个默认全部反过来。任何东西都不能在 Host 自己的机器上运行，因为那块磁盘和那些进程同时属于每个账号；一个账号改动的任何东西也不能波及另一个账号。而产品存在的理由——会话、工作区、记忆、同步、桌面续接——仍要照常工作。

## 决策

`@aeven/hosted-app` 是叠加在 `@aeven/web-app` 之后的补丁层，`PROFILE_TEMPLATES.hosted` 组合 base、web 与 hosted。`avn hosted` 以 `AVN_HOME` 指定本次部署的状态目录，以 `AVN_HOSTED_PORT`（3085）、`AVN_HOSTED_HOST` 和 `AVN_HOSTED_TRUSTED_HOSTS`（浏览器访问使用的名字）启动它。

补丁把两条规则直接写成行。凡会在 Host 自己的机器上运行的行一律禁用：`code-runtime`、shell、文件系统与文件搜索工具、终端、浏览器、设备、computer-use、workflow 与 ralph 工作线程、Codex 与 Claude Code 子代理、插件自省、工作区文件、目录选择器以及技能目录。预设的工具行由同一份补丁一并禁用，因此没有哪个预设能把它们重新打开。Host 保留网页搜索与抓取、imagine、附件、记忆，以及同进程内的子代理委派。

另一半是账号之间的边界。`settings` 保留账号分节（`accounts: true`），一个账号自己的分节只对它自己解析；`settings-controller.writable: false` 拒绝一切由浏览器发起的 Host 文档写入，`workspace-controller.folders: false` 去掉共享 Host 本就不该指名的文件夹。`memory-memos` 为每个账号保留自己的家目录（`accounts`），并按产生记忆的工作区来归属项目记忆，而不是共用同一个项目作用域，同时在同步时即打开，使回来的账号在第一轮对话之前就建好记忆；每个账号的记忆工作都有上限，一个账号不能拖慢另一个。`sync-yjs` 以 `keepConnected: true` 连接 `wss://aeven.io/sync`，于是 Host 成为每个登录账号的又一台设备，并通过首次登录连接时中继签发的授权保持最新。

身份只在部署需要时才跟随账号：当 `settings.accountSections` 为真时，会话控制器读取该账号的默认模型；否则单账号 Host 仍用组合条目。仅凭指纹读取图片（不带会话的 `/api/attachment-image?id=…`）在共享 Host 上以 `SESSION_REQUIRED` 拒绝；浏览器改用会话作用域的路由，读取权限来自该会话自己的日志。`ui-desktop-handoff` 与桌面应用的 `aeven://` 协议注册，使托管会话可以在用户自己的机器上继续。

## 备选方案

**挂载桌面版的能力面、靠工具策略兜底**被否决：真正生效的是组合本身而不是策略回调，而且共享磁盘意味着一个账号的文件工具能碰到另一个账号的数据。

**所有账号共用一份设置文档、只拒绝浏览器写入**被否决：那样一个账号的模型选择、语言或个人化会应用到所有人，这是与写入路径不同的另一个缺陷。

**用指纹读取图片**在共享 Host 上被否决，尽管它更省更可永久缓存：指纹本身就成了授权，任何持有一个 id 的登录账号都能读到别人的图片。会话作用域的读取放弃了不可变缓存头，换掉了这条路。

**复用桌面的工作区文件同步**被否决：托管 Host 不持有工作区文件夹，文件同步消费者没有任何东西可监视。

## 影响

一个托管 Host 是它服务的每个账号的一台设备，并把该账号的会话、记忆和同步数据库保存在各自目录里。这些数据没有静态加密，因此运营这台 Host 的人可以读取；静态加密不属于本次改动。

托管会话不提供任何代码执行，同时也去掉了所有能查看 Host 上文件的工具，包括那些看起来无害的；托管图片也不再获得永久缓存的 URL。

面向公开部署的按账号配额、速率限制以及防滥用注册不属于本次改动。

## 验证

针对性测试覆盖了组合出的托管行与启动参数；设置控制器在保留账号分节的同时拒绝浏览器写入；关闭文件夹的工作区控制器；同步提供者为已登录账号保持连接、应用有界帧并保存中继授权；保险库的 passkey 与授权路径；以及按账号解析的记忆家目录。写下这条记录之前，web 与 hosted 组合已在真实浏览器会话中对生产 API 与中继验证过。
